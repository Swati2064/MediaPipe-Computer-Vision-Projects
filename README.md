# 🖥️ MediaPipe Computer Vision Projects

A collection of real-time Computer Vision applications built using **Python**, **OpenCV**, and **Google MediaPipe**.

This repository demonstrates multiple AI-powered vision tasks including face detection, hand tracking, body pose estimation, object detection, motion tracking, and 3D face transformation.

---

## 🚀 Features

- 👤 Face Detection
- ✋ Hand Landmark Detection
- 🤲 Face and Hand Landmark Detection
- 🧍 Human Pose Estimation
- 🎥 Real-Time Pose Tracking
- 📹 Pose Tracking from Video
- 📦 3D Object Detection (Image)
- 🎬 3D Object Detection (Video)
- 😀 MediaPipe 3D Face Mesh
- 🔄 3D Face Transformation
- 🎭 Face Replacement Demo
- 👕 Cloth Color Change using Pose Detection
- 🖐️ Instant Motion Tracking

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/MediaPipe-Computer-Vision-Projects.git
```

Move into the project directory

```bash
cd MediaPipe-Computer-Vision-Projects
```

Install the required libraries

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

Example

```bash
python "Hand landmarks detection.py"
```

or

```bash
python "Object Detection with Web Cam using MediaPipe.py"
```

or

```bash
python "On-device, Real-time Body Pose Tracking with MediaPipe BlazePose.py"
```
